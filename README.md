# Asyncio TCP Port Scanner
Asyncio TCP Port Scanner is made using python

## Features
* **Port Scanning**
* **TCP Protocol**
* **Async (Asyncio)**
* **Clean Command line Arguments**

## Installation
1.Make sure you have installed Python(https://python.org/).
2.Clone this Repo in your computer.
3.Optional: if you want you can use virtual env - python -m venv venv
4.install the required libraries - pip install -r requirements.txt
5.Run - python main.py -h
